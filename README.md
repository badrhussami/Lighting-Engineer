# Lighting Engineer

A Copilot custom agent for entertainment and architectural lighting projects, backed by a curated, source-led reference library.

## Use the agent

In GitHub Copilot, select **Lighting Engineer** and describe your project, question, or deliverable. For technical design questions, include the project location, system/equipment details, and constraints when available.

## Knowledge and references

The agent's guidance and curated authoritative references are in [`docs/README.md`](docs/README.md). Start there for lighting-design and photometry guidance, control protocols, electrical safety and rigging references, and manufacturer/software documentation.

The library links to sources rather than reproducing copyrighted standards or manuals. A reference is not automatically applicable: verify the current edition, local adoption, project requirements, equipment revision, and site conditions with the relevant authority and qualified professionals.

## Important boundary

This project provides technical assistance, not engineering approval, electrical or rigging sign-off, or a code-compliance determination. Site-specific high-risk work must be reviewed and performed by appropriately qualified people.
