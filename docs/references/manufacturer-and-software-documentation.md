# Manufacturer and software documentation

Use the exact manufacturer's manual, datasheet, photometric file, personality/library entry, software version, and revision for the equipment or workflow under discussion. Product families and similar-looking models can differ substantially. The links below are official starting points, not an endorsement or a substitute for model-specific documents.

## Console and control platforms

- [ETC Eos software and manuals](https://www.etcconnect.com/eos-software/) — current Eos downloads, online operations manual, version-specific manuals, supplements, and reference documents. Match instructions to the console/software version.
- [ETC Eos Family support](https://support.etcconnect.com/ETC/Consoles/Eos_Family) — official support and documentation portal.
- [MA Lighting grandMA3 online help](https://help.malighting.com/grandMA3/2.2/HTML/qsg_welcome.html) — official online documentation; choose the documentation edition that matches the installed software. The link is a versioned guide, so check the portal's version selector.
- [MA Lighting downloads](https://www.malighting.com/downloads/) — official product downloads and manuals.

## Design, CAD, and visualization

- [DIALux downloads](https://www.dialux.com/en-GB/download/) and [DIALux support](https://www.dialux.com/en-GB/support) — official software, version history, help, learning material, and manufacturer luminaire catalogs. Record the evo version and verify calculation inputs and imported photometric data.
- [IES Lighting Library](https://ies.org/standards/lighting-library/) — authoritative standards and application guidance; access may require subscription/purchase.

## Individual fixture and accessory documentation

For each product, seek the manufacturer-published documents for the exact model and revision:

- installation/operation/maintenance manual and safety warnings;
- datasheet/nameplate, environmental/IP and temperature limits, and approved mounting accessories;
- photometric file and its test/measurement basis;
- DMX/RDM personality or profile, channel modes, addressing, and data-loss behavior;
- firmware release notes, compatibility notes, and service bulletins;
- power, connector, cable, and accessory requirements.

If the source page does not clearly identify model and revision, treat it as unverified. Ask for the model label or manual rather than inferring values from an adjacent product.

## Technical software workflow

When answering version-sensitive software questions, identify the software/console model and version first. Prefer current official manuals and release notes; mark menu paths or behavior that may differ by version. For code or control API examples, identify the library/API version, cite its official documentation, and suggest testing in a safe, isolated setup before connecting to production equipment.
